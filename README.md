# 拼音乐园 🐼

小学生（一、二年级）练习汉语拼音的网页游戏。纯 HTML/CSS/JS，不需要安装或构建，**双击 `index.html` 就能玩**，平板和手机优先。

## 玩法

| 模式 | 内容 |
| --- | --- |
| 📖 拼音卡片 | 声母 23 个、韵母 24 个、整体认读音节 16 个、四声和轻声。点卡片可以听读音，看例词 |
| 🗺️ 闯关练习 | 按部编版顺序分成 18 关，每关 10 道选择题，按正确率得 1–3 颗星，拿到星星才能解锁下一关（家长可以设置全部解锁） |
| 👂 听音选择 | 听读音，选拼音或词语 |
| 🧩 拼音拼装 | 给每个字选声母、韵母、声调，拼出完整的拼音 |
| ✏️ 看词写拼音 | 用屏幕上的拼音键盘写拼音，写在四线格里。电脑上也可以直接打字：字母键输入，`v` 打 ü，`1–4` 选声调，`5` 是轻声，回车检查 |
| ⏱️ 限时挑战 | 60 秒内尽量多答题，连续答对有额外加分，记录最高分 |
| 📒 错题本 | 答错的题自动收进来，记录错了几次。复习时连续答对 2 次就移出错题本 |

题型有：听音认声母韵母、找声母或韵母、选声调、拼读（如 p + íng → píng）、看词选拼音、看拼音选词。每道题答完都会给出带拼音的例词，点一下可以朗读。

## 目录

```
index.html        页面结构
css/style.css     样式
js/pinyin.js      拼音工具：标声调、拆分和组合音节、生成容易混淆的干扰项
js/data.js        字母表和词库（按教材分组）
js/store.js       本地存储：星星、最高分、错题本
js/sound.js       朗读（浏览器自带的中文语音）和音效
js/questions.js   出题
js/quiz.js        答题流程：选择题、拼装、软键盘
js/app.js         页面切换和各个界面
audio/            预先生成的朗读音频 + manifest.js 清单
tools/gen_audio.py  生成音频的脚本
```

## 添加词语

在 `js/data.js` 里找到对应的单元，往 `words` 里加一行 `['词语', '拼音', 'emoji']`。拼音用数字表示声调，`5` 是轻声，`ü` 可以写成 `v`，例如：

```js
['绿叶', 'lv4 ye4', '🍀'],
['葡萄', 'pu2 tao5', '🍇'],
```

字数要和拼音的音节数一样，不一样的话这个词会被跳过，控制台会提示。

## 说明

- **读音**：所有字母、例字和词语都预先用微软神经网络语音（晓晓）生成成了 mp3，放在 `audio/` 里，可以离线播放，在每台设备上听起来都一样。缺少音频的才会退回浏览器自带的朗读。
- 声母、韵母的读音用代表字来读（例如 b 读「玻」，ün 读「晕」）。**ei（诶）、eng（鞥）、ong（翁）** 没有完全对应的常用字，读音只是接近。想要更准的话，可以自己录一段，覆盖 `audio/诶.mp3`、`audio/鞥.mp3`、`audio/翁.mp3`。
- 进度都保存在当前浏览器里，清除浏览器数据会一起清掉。
- 拼音用的是 Andika 字体，a 和 g 的写法和课本一致，需要联网加载。离线时会换成系统字体，不影响使用。

## 部署到 GitHub Pages

这是一个纯静态网站：仓库根目录就是网站根目录，不需要安装依赖或构建。推荐用 GitHub Pages 的「从分支部署」。

### 第一次部署

1. 在 GitHub 上新建一个**公开**仓库，例如 `pinyin`（免费账号的 Pages 需要公开仓库）。初始化选项都留空，本地已经有文件了。
2. 在项目目录初始化 Git 并推送（把 `<你的用户名>` 换成 GitHub 用户名）：

   ```bash
   cd /Users/daniel.feng/git-repo/pinyin
   git init -b main
   git add -A
   git commit -m "拼音乐园"
   git remote add origin https://github.com/<你的用户名>/pinyin.git
   git push -u origin main
   ```

   如果 Git 提示没有配置身份，先执行一次：

   ```bash
   git config user.name "你的名字"
   git config user.email "你的邮箱"
   ```

3. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 里把 **Source** 选成 **Deploy from a branch**，分支选 **main**、目录选 **/ (root)**，点 **Save**。
4. 等 1–2 分钟，访问：

   ```
   https://<你的用户名>.github.io/pinyin/
   ```

   仓库名如果取成 `<你的用户名>.github.io`，网址就是 `https://<你的用户名>.github.io/`，页面会直接放在根路径。

### 以后更新

改完文件后正常提交推送，Pages 会自动重新发布：

```bash
git add -A
git commit -m "更新内容"
git push
```

可以在仓库的 **Actions** 页面看到每次发布的状态。

### 注意事项

- 所有资源都用相对路径（`css/`、`js/`、`audio/`），所以部署在 `/pinyin/` 这样的子路径下也能正常工作。以后加文件时不要写成 `/js/...` 这种以 `/` 开头的绝对路径，否则会指向域名根目录。
- `index.html` 必须留在仓库根目录，GitHub Pages 默认用它作为首页。
- `.nojekyll` 已经加好，用来跳过 Jekyll 处理，避免特殊目录或文件被忽略。
- 仓库大小限制 1 GB、每月流量 100 GB，当前项目约 2.6 MB（主要是 `audio/` 里的 214 个 mp3），完全够用。
- 网站里的星星、最高分、错题本存在浏览器的 `localStorage` 里，按域名隔离：`github.io` 上的进度和本地双击打开时的进度不互通，清缓存会丢失。
- 字体（Google Fonts）需要联网加载；国内访问 `github.io` 有时较慢，可以换用 Cloudflare Pages、Netlify、Vercel，或给 Pages 绑定自己的域名。

## 重新生成音频

加了新词以后运行下面的命令，只会生成缺少的音频：

```bash
pip install edge-tts
python3 tools/gen_audio.py
```

- `--force`：全部重新生成。
- `--voice zh-CN-XiaoyiNeural`：换一个更活泼的声音。
- `--rate=-20%`：读得更慢。

已有的文件不会被覆盖，所以自己的录音可以放心放进 `audio/`。文件按朗读的文字命名，比如 `苹果.mp3`；声母、韵母的音频按代表字命名，比如 b 是 `玻.mp3`。脚本会同时更新 `audio/manifest.js`，游戏按这个清单决定放哪个文件。
